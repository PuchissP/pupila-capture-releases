# Pupila Capture — releases

ไฟล์ติดตั้ง Android ของ **Pupila Capture** แอปเก็บวิดีโอการตอบสนองของรูม่านตาต่อแสง (PLR) สำหรับงานพัฒนาและวิจัย **ไม่ใช่เครื่องมือวินิจฉัยโรค**

## ติดตั้ง

1. เปิดหน้า [release ล่าสุด](https://github.com/PuchissP/pupila-capture-releases/releases/latest) บนมือถือ Android (8.0 ขึ้นไป)
2. ดาวน์โหลดไฟล์ `pupila-capture-<เวอร์ชัน>.apk` แล้วเปิดติดตั้ง และอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" เมื่อถูกถาม

หลังติดตั้งแล้ว แอปจะแจ้งเมื่อมีเวอร์ชันใหม่ และอัปเดตได้จากในแอปเลย

## ตรวจสอบไฟล์

แต่ละ release มี `update.json` ที่ระบุ SHA-256 ของ APK แอปจะตรวจค่านี้ก่อนติดตั้งทุกครั้ง

ทุกเวอร์ชันเซ็นด้วยใบรับรองเดียวกัน ลายนิ้วมือ SHA-256:

```
e99029ac84a439fb3553af5e4eee90bae9c659bc7b011ed2e94363c65becd5b8
```

repo นี้มีแค่ไฟล์ติดตั้ง ซอร์สโค้ดอยู่ใน repo แยกที่เป็น private
